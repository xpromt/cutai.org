# Cut AI

Stop AI. Or don't. We're not your parents.

A satirical landing page mocking the endless "AI-powered" startups flooding the internet.

## Features

- FAQ with confidence scores that don't make sense
- Fake stats that are statistically impressive
- A manifesto generator that says nothing
- A "Cut AI" button that does nothing useful
- Cookie banner that never truly goes away

## Tech Stack

- React + TypeScript
- Framer Motion
- Tailwind CSS
- Vite

## Development

```bash
npm install
npm run dev
```

## Deploy

Static site. Build and serve:

```bash
npm run build
```

The `dist/` folder contains the production build.
